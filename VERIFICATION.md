After the recorded correction, an independent AI technical reviewer checked
clean exported-source setup and the application against the existing exact
model profile. The review covered 24 unit tests, 42 independent groups, 320
hard-filter cases, 47 API requests and 15 genuine embedding POSTs. Separate
browser checks covered phone-size UI, keyboard behavior, stale-response handling
and date behavior across three time zones. These counts describe different
check sets, not a count of independent users or statistical reliability.

The checked behavior includes a working local recommendation path, strict
input rules, exact-cent boundaries, source/explanation distinctions and
explicit errors. Price and availability refer to a synthetic catalog, not
real suppliers. Similarity scores measure text similarity, not confidence
or verified service quality. The controlled delayed-request demonstration
is not a real model-service outage.

That product review did not cover acquiring the model. A later author check
on September 28, 2026 downloaded it into an empty, separate store, checked all
manifest/blob hashes, and obtained genuine embeddings. After correcting an
author harness's mistaken response-field assumption, a separate recheck used
the same files and passed the four example paths plus 24 tests. All 22 source
files remained unchanged. The original failed harness result is preserved;
it was not relabeled as a complete pass. See [MODEL-SETUP.md](MODEL-SETUP.md).

Still not established by these checks:

- installation on an empty machine or across all operating systems: the
  fresh model-store check reused an already-installed runtime;
- production operations, public hosting security or real-world availability;
- identical AI generation or ranking across different model versions;
- human voice quality, complete film review or permission to publish;
- clearance of public distribution rights or a public download URL.

The check counts above are a summary of the independent report, not newly
executed checks during packaging. The packaging process separately verifies
archive extraction, unchanged source hashes and local relative links. Internal
audit paths and raw conversations are not included in the viewer companion.
